# Official source registry

Every claim in this knowledge base traces to an official page listed in one of
these files. All of them were checked against Apple documentation on
**2026-08-19**, during the iOS 26 / Xcode 26 SDK cycle. Apple documentation
changes, so re-open the page before relying on a version-sensitive API,
availability annotation, entitlement, or policy.
